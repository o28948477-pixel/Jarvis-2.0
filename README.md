# JARVIS

আমার ব্যক্তিগত এআই সহকারী। এটি একটি সাধারণ ওয়েবসাইট, যা GitHub Pages-এ বিনামূল্যে চলে।

## ফাইলগুলো কী কাজ করে

| ফাইল | কাজ |
|---|---|
| `index.html` | পেজের কাঠামো। এখানে শুধু লেখার জায়গাগুলো আছে |
| `colors.css` | **সব রং এখানে।** থিম বদলাতে চাইলে শুধু এই ফাইল খোলো |
| `fonts.css` | **ফন্ট ও লেখার আকার এখানে** |
| `style.css` | লেআউট ও বোতাম-কার্ডের নকশা (রং ছাড়া) |
| `motion.css` | সব অ্যানিমেশন |
| `state.js` | সংরক্ষিত তথ্য ও কাজের ধরন চেনা |
| `updates.js` | অনুমোদন কেন্দ্র (approve, reject, rollback) |
| `views.js` | সব পেজের নকশা (Dashboard, Settings, API, Skills ...) |
| `render.js` | পেজ আঁকা ও বোতামের কাজ |
| `api.js` | API: Worker সংযোগ ও পরীক্ষা |
| `diag.js` | Diagnostics পরীক্ষা |
| `lock.js` | PIN লক |
| `chat.js` | চ্যাট, History, ফাইল সংযুক্তি, ভয়েস |
| `brain.js` | অফলাইন ব্রেন (হিসাব, কাজের তালিকা, আবেগ, শেখানো) |
| `reply.js` | উত্তর দেখানো ও বার্তা পাঠানো |
| `fx.js` | পেছনের কণার অ্যানিমেশন |
| `main.js` | অ্যাপ চালু হওয়ার কাজ |
| `worker.js` | **GitHub-এর জন্য নয়।** এটি Cloudflare Worker-এ বসাতে হয় |

## GitHub-এ কীভাবে দেবে

1. ZIP ফাইলটি ফোনের Files অ্যাপে খুলে (Extract) সব ফাইল বের করো।
2. github.com-এ রিপোজিটরি খুলে **Add file** → **Upload files** চাপো।
3. সব ফাইল একসাথে বেছে নাও (`README.md` আর `worker.js` সহ রাখলেও সমস্যা নেই)।
4. **Commit changes** চাপো।
5. **Settings** → **Pages**-এ Branch `main` আর folder `/ (root)` দিয়ে **Save** চাপো।

সব ফাইল রিপোজিটরির একদম ওপরের স্তরে থাকবে, কোনো ফোল্ডারের ভেতরে নয়।

## পরে কিছু বদলাতে হলে

শুধু যে ফাইলটি বদলাবে সেটিই আবার আপলোড করো, বাকি ফাইল ছুঁতে হবে না। অথবা GitHub-এ ফাইলটি খুলে পেন্সিল আইকন চাপলে সরাসরি সম্পাদনা করা যায়। বদলানোর পর **Commit changes** চাপো।

## নিরাপত্তা

- সাইটে কোনো API key বা পাসওয়ার্ড নেই।
- Gemini key শুধু Cloudflare Worker-এর Secret ঘরে থাকে।
- এই সাইট শুধু `*.workers.dev` ঠিকানার Worker-এর সঙ্গে কথা বলতে পারে। নিজের ডোমেইন ব্যবহার করলে `index.html`-এর `connect-src` অংশে সেই ডোমেইন যোগ করতে হবে।
